#  Free TryHackMe SOC Labs – SIEM, Threat Detection, DFIR & Blue Team Practice

A curated collection by **Rynex Security** featuring **free TryHackMe rooms** focused on **Security Operations Center (SOC)** training. Whether you're an aspiring **SOC Analyst (L1/L2)**, **Blue Teamer**, or **cybersecurity student**, these hands-on labs cover essential skills including **SIEM investigations**, **incident response**, **threat hunting**, **Windows event analysis**, **network forensics**, and **endpoint detection**.

---

##  Why This Collection?

This learning path is designed to help you build practical Blue Team skills and prepare for industry certifications such as:

- CompTIA CySA+
- Microsoft SC-200
- Blue Team Level 1 (BTL1)
- Security Blue Team (SBT)
- SSCP
- GCIH

By completing these labs, you'll gain hands-on experience with:

-  Alert Triage
-  Incident Response Playbooks
-  Threat Hunting
-  Windows Event Log Analysis
-  Linux Log Analysis
-  APT Detection
-  SIEM Platforms (Splunk, ELK, Wazuh)
-  Endpoint Detection & Response (EDR)
-  Network Traffic Analysis
-  Digital Forensics

##  How to Use This Collection

1. Create a free TryHackMe account.
2. Complete the rooms in the order that best matches your experience.
3. Take notes and document your findings.
4. Practice writing investigation reports after each lab.
5. Revisit completed rooms to reinforce concepts.
